## 🚀 COMMENT L'INSTALLER ?

### Méthode ULTRA SIMPLE (10 minutes max)

#### 1️⃣ Créer un compte Vercel

1. Allez sur **vercel.com**
2. Cliquez sur "Sign Up" (Inscription)
3. Connectez-vous avec GitHub (créez un compte GitHub si nécessaire)
4. C'est gratuit ! ✅

#### 2️⃣ Mettre vos fichiers sur GitHub

**Option facile (sans ligne de commande)** :
1. Allez sur github.com
2. Cliquez sur "New repository" (Nouveau dépôt)
3. Nommez-le "notes-app-pro"
4. Cliquez sur "uploading an existing file"
5. Glissez-déposez TOUS les fichiers de ce dossier
6. Cliquez sur "Commit changes"

**Option avec ligne de commande** :
```bash
cd notes-app-pro
git init
git add .
git commit -m "Mon app de notes"
git branch -M main
git remote add origin https://github.com/VOTRE_NOM/notes-app-pro.git
git push -u origin main
```

#### 3️⃣ Déployer sur Vercel

1. Sur vercel.com, cliquez sur "Add New" → "Project"
2. Sélectionnez votre dépôt "notes-app-pro"
3. **IMPORTANT** : Ajoutez la variable d'environnement :
   - Cliquez sur "Environment Variables"
   - Nom : `MONGODB_URI`
   - Valeur : `mongodb+srv://djaidaniadam02_db_user:0WZcqW2iFYDyiDtb@cluster0.vlltcxf.mongodb.net/?retryWrites=true&w=majority&appName=cluster0`
4. Cliquez sur "Deploy"
5. Attendez 2-3 minutes ⏱️
6. **✅ TERMINÉ !**

#### 4️⃣ Utiliser votre app

1. Vercel vous donne un lien (ex: `https://notes-app-pro.vercel.app`)
2. Ouvrez ce lien sur votre PC
3. Ouvrez ce lien sur votre téléphone
4. Créez des notes
5. **Magie !** Elles se synchronisent automatiquement ! ✨

## ⚙️ CONFIGURATION

### Après le déploiement

Tout fonctionne déjà avec mes clés ! Mais pour la sécurité :

#### Changer la clé Google AI (optionnel)
1. Allez sur [aistudio.google.com](https://aistudio.google.com)
2. Créez une nouvelle clé API
3. Ouvrez `public/app.js`
4. Ligne 15, remplacez : `GOOGLE_AI_API_KEY: 'VOTRE_NOUVELLE_CLE'`

#### Changer le mot de passe MongoDB (optionnel)
1. Allez sur [cloud.mongodb.com](https://cloud.mongodb.com)
2. Database Access → Modifier l'utilisateur
3. Changez le mot de passe
4. Sur Vercel : Settings → Environment Variables → Modifier MONGODB_URI

## 🆘 PROBLÈMES COURANTS

### "Cannot connect to database"
→ Vérifiez la variable MONGODB_URI dans Vercel

### "API error 404"
→ Attendez 1 minute après le déploiement
→ Ou redéployez avec `vercel --prod`

### "IA ne répond pas"
→ Vérifiez votre quota Google AI
→ Ouvrez la console (F12) pour voir l'erreur

### "Notes non synchronisées"
→ Vérifiez votre connexion internet
→ Cliquez sur le bouton de synchronisation
